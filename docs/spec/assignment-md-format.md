# md 과제 파일 양식

> 상태: **구현됨** — `backend/app/services/assignment_md.py`, `POST /classes/{class_id}/assignments/extract`, 테스트 `backend/tests/test_assignment_md.py`.
> 기준 샘플: [samples/c-binary-assignment.md](samples/c-binary-assignment.md) (시드 과제 · `drafts {source: "SAMPLE"}`도 이 파일을 읽는다).
> 규칙(정규식)으로만 읽는다. AI로 추출하지 않는다. PDF는 아직 없음(M3 여유 있으면 같은 양식 + 텍스트 변환).

## 전체 모양
```markdown
# 과제: <제목>                ← 선택. 과제 정보에 제목이 없을 때만 쓴다

## 과제 정보
- 제목: …                     (필수, 100자 이하)
- 과목: …
- 대상: …
- 언어: C                     (필수: C · Python · Java · JavaScript, 대소문자 무시)
- 마감: 2026-12-05 23:59      (선택, 한국 시간)
- 설명: …                     (한 줄)

---
## 문항 1
- 유형: 객관식                (필수: 객관식 · 출력 예측 · 코드 작성 · 간단 제작)
- 배점: 10                    (필수, 0 이상 정수)
- AI 도움: 사용               (선택: 사용 · 사용 안 함, 기본 사용)

### 문제
…(여러 줄, 마크다운 그대로)

### <칸 이름> [교수자 전용]
…
```
- 문항은 `## 문항 N`으로 시작한다. 문항 사이의 `---` 구분선은 있어도 없어도 된다.
- `[교수자 전용]` 표시는 사람이 읽기 위한 것이다. 학생에게 무엇이 보이는지는 **칸 이름**이 정한다(아래 표, 불변식 I8).
- 위 순서와 다른 칸 이름은 무시한다.

## 유형별 칸
| 칸 | 객관식 | 출력 예측 | 코드 작성 | 간단 제작 | 학생에게 |
|---|---|---|---|---|---|
| `### 문제` | 필수 | 필수 | 필수 | 필수 | 보임 |
| `### 선택지` (`1. …` 번호 목록) | 필수(2개 이상) | | | | 보임 |
| `### 코드` (코드 블록) | | 선택 | | | 보임 |
| `### 시작 코드` (코드 블록) | | | 선택 | | 보임 |
| `### 공개 테스트` | | | 공개 · 숨김 중 1개 이상 | | 보임 |
| `### 정답` | 필수(선택지 번호) | 필수 | | | 🔒 |
| `### 인정 답안` (`- …` 목록) | | 선택 | | | 🔒 |
| `### 오개념` (`- 번호: 설명`) | 선택 | | | | 🔒 |
| `### 숨김 테스트` | | | 위와 같음 | | 🔒 |
| `### 모범 답안` (코드 블록) | 선택 | 선택 | 선택 | 선택 | 🔒 |
| `### 채점 기준` (`- …` 목록) | | | | 필수(1개 이상) | 🔒 |
| `### 참고 입출력` (테스트 모양) | | | | 선택 | 🔒 채점 기준 맨 뒤에 붙는다 |
| `### 확인 문제` | 선택 | 선택 | | | 🔒 (이해 확인 단계에서만) |

### 번호
선택지 · 객관식 정답 · 오개념 번호는 **파일에서 1부터** 쓴다. 저장할 때 0부터로 바꾼다(schema `AnswerKey`).

### 테스트 (`공개 테스트` · `숨김 테스트` · `참고 입출력`)
````markdown
```text
입력: 5
출력: 101
---
입력: 1011 110
출력: 10001
```
````
- `입력:` 다음 줄(들) 뒤에 `출력:`. 값이 여러 줄이면 다음 줄에 이어 쓴다. `---`로 테스트를 나눈다.
- 입력은 끝에 줄바꿈을 붙여 표준 입력으로 넣는다(`5` → `"5\n"`). 입력이 비어 있으면 빈 입력.
- 출력 비교는 각 줄 끝 공백 · 마지막 줄바꿈을 무시한다(schema D23).

### 확인 문제
```markdown
### 확인 문제 [교수자 전용]
- 유형: 객관식
- 문제: 2진수 `1101`을 10진수로 바꾸면 얼마인가?
- 선택지: 1. 13 / 2. 11 / 3. 1101 / 4. 3
- 정답: 1
```
- 유형은 객관식 · 출력 예측만. 선택지는 한 줄에 `/`로 나눈다. 출력 예측은 `- 정답:`만.

## 양식 오류
틀린 곳을 **모두 모아** 한 번에 돌려준다. `400 VALIDATION_FAILED`, `message` = `과제 파일 양식이 맞지 않아요.` + 줄마다 한 건.
```
과제 정보: '- 언어:'는 C · Python · Java · JavaScript 중 하나여야 해요 (지금: '코볼')
문항 2: '- 배점:'은 0 이상의 정수여야 해요
문항 2 정답: 1부터 2 사이의 선택지 번호여야 해요 (지금: '5')
문항 3 공개 테스트 1번째: '입력:' 다음 줄에 '출력:'이 있어야 해요
```
- 파일은 UTF-8 텍스트, 200KB 이하, 확장자 `.md` · `.markdown` · `.txt`.
- 추출 결과는 **저장하지 않은 초안**(`seq: null`)이다. 교수자가 확인 · 수정한 뒤 `POST /classes/{class_id}/assignments`로 저장한다. AI 정책은 클래스 기본값.
