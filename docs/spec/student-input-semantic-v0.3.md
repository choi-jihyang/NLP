# 대화 원문 의미 검토 보충 규칙 v0.3

상태: **AI 의미 검토 초안 — 사람 승인 전**. 날짜: 2026-11-16.
기본 의미 기준은 [v0.1](student-input-labeling.md)을 따른다.
v0.2는 약한 자동 주석 방식이며, v0.3은 원문·허용 이력을 읽은 추가 의미 검토에만 적용한다.
서비스 API·응답 정책은 변경하지 않는다.

## 추가 판단 기준

- S01: 과거 학생 발화가 있어도 일반 질문·수업 규칙 요약뿐이면 누적 시도는 false다.
  과거 AI가 코드를 제공했다는 사실은 학생 시도가 아니다.
- S02: 학생이 자신의 글 검토를 요청한 뒤 실제 문장을 보내면 관찰 가능한 작성 흔적으로 인정한다.
  독자 작성 여부를 검증했다는 뜻은 아니다.
- S03: AI 질문에 구체 적용 예시를 만들거나, 학생이 문제 지점을 특정하고 논거를 제시하면 시도다.
  개념명 나열·배웠다는 주장·단순 수용만으로는 시도가 아니다.
- S04: 같은 글의 분량 확장·지지 문장 추가·구체 과제의 표/선택지 정답은 완성 산출물 요청이다.
  과제 문항을 다시 제시한 것을 자기 풀이로 세지 않는다.
- S05: 이미 주어진 수치·AI 답변을 표·마크다운으로만 정리하는 요청은 새 답안 대행으로 세지 않는다.
  다만 입력 수치의 출처가 불명확하면 시도 여부는 별도로 보류한다.
- S06: 현재와 다른 문항으로 바뀌었으면 이전 문항의 근거를 자동 승계하지 않는다.
  이전 문항에도 수행 흔적이 전혀 없으면 현재의 시도 false 판단에 경계 추정이 필요하지 않다.
- S07: 외부 이미지 URL 내용은 열람 없이 추정하지 않는다. 이를 근거로 원격 링크를 자동 방문하지 않는다.
- S08: 인사·감사만 있는 현재 발화의 학습 맥락은 false다. 누적 시도는 과거 학생 입력을 따로 살핀다.
- S09: 앞 AI의 사실 오류·부정확한 문법 설명을 주석의 정답 근거로 사용하지 않는다.
  이번 작업은 학생 입력의 의도·수행 흔적을 주석하며 AI 답변의 사실성을 보증하지 않는다.

## 주석 기록

각 행에 현재 시도와 누적 시도를 따로 저장한다.
누적 시도 양성이 과거 학생 메시지에만 있으면 그 턴 번호와 정확한 문자 인용을 남긴다.
허용 입력 전체를 읽었어도 출처·과제 범위가 불명확하면 null을 유지한다.
기존 라벨·규칙 결과는 이전 버전에 보존하고 새 행에 대체 관계를 남긴다.
AI 단독 검토이므로 human_reviewed=false, gold_eligible=false다.
