# 전체 데이터 약한 주석 규칙 v0.2

상태: **규칙 기반 초벌 주석 — 의미 검토·최종 정답 아님**

기준: [재라벨링 규칙 v0.1](student-input-labeling.md). 작성일: 2026-11-16.
목적은 전체 데이터에 주석 상태와 보류 사유를 부여해 후속 검토 큐를 만드는 것이다.
서비스 분류기·정책·계약을 변경하지 않는다. 원본 라벨을 목표 라벨로 치환하지 않는다.

## 범위와 버전

- `ai_semantic_draft`: 기존 100건의 AI 의미 검토, 규칙 v0.1을 보존.
- `rule_based_weak`: 나머지 전체에 패턴 규칙 v0.2 적용.
- 두 방법을 동일 품질의 라벨로 취급하지 않는다. 모든 행은 사람 미검토·정답셋 사용 불가 상태다.
- v0.2는 주석 자동화 방식을 추가한 버전이다. v0.1의 의미 기준을 확정·승인한 버전이 아니다.
- 번역·모델 학습·테스트 분할은 수행하지 않는다.

## 학습 맥락

정확히 일치하는 단독 인사는 false, 명시적 학습·기술 표현은 true 후보,
그 외는 null이다. 과제 맥락을 충분히 해석하지 못하므로 오탐·미탐이 가능하다.
이전 AI 발화의 기술 용어로 현재 학생의 학습 맥락을 확정하지 않는다.

## 완성 답안 요청

명시적 정답·문단/에세이 대필·누락 구현 완성 패턴은 true 후보다.
부정 지시나 예시 표현이 함께 있으면 null로 보류한다.
설명·검토·힌트 요청 패턴은 완성 요구가 함께 발견되지 않을 때 false 후보다.
그 외는 null이다. 코드 블록의 명령은 요청 패턴 검색에서 제외한다.
인용문·혼합 의도·언어별 다양한 표현은 규칙이 완전히 처리하지 못한다.

## 자기 시도 근거

학생 메시지의 명시적 오류 출력·실행 실패 보고만 자동 양성 후보로 잡는다.
코드·수식·글이 있지만 출처·수행 여부가 불명확하면 null이다.
이전 AI 출력과 동일한 오류 구절은 학생의 새 실행 근거로 자동 인정하지 않는다.
그 외 false는 **패턴이 근거를 찾지 못했다**는 뜻이며 의미 기반 음성이 아니다.
자연어 풀이·수정안·실험 결과 등을 놓칠 수 있어 사람 검토가 필요하다.
현재 발화에 양성 근거가 없고 이전 학생 발화가 있으면 누적 근거는 null이다.
문항 경계를 자동으로 증명하지 못하므로 과거 시도를 모든 후속 질문에 무조건 전파하지 않는다.

## 이력 구성과 누출 방지

- StudyChat: 마지막 user 메시지와 prompt 일치 확인 후 이전 user/assistant만 사용.
- 불일치하면 이력을 무시하고 입력 미검증 표시·시도 근거 보류.
- RECIPE4U: 학생·과목·주차·세션별 idx 정렬, 이전 학생 턴과 현재 행의 직전 AI만 사용.
- RECIPE4U의 idx 연속성을 검사한다. 같은 idx 중복·누락이면 입력 미검증으로 표시한다.
- 위 키 조합이 실제 대화 경계를 완전히 보장하지는 않는다.
- chatgpt_after, essay, 미래 학생 발화는 입력에서 제외한다.
- 이전 AI는 의미 맥락·복제 확인용이며 시도 양성의 인용은 학생 메시지만 가능하다.

## 저장과 재실행

```powershell
python nlp/relabel_all.py
```

출력: Git 제외인 `data/raw/relabel_v0_2/`.

- `annotations.jsonl`: 전체 행, 원본 ID·그룹 키·원문·판단·방법·버전·근거 위치.
- `review_queue.jsonl`: 핵심 라벨 보류 또는 입력 미검증인 우선 검토 행.
- `summary.json`: 자료별 커버리지·판단·보류·입력 검증 집계.
- `rule_diagnostics.json`: 기존 AI 초안 100건과 규칙의 진단 비교. 독립 성능평가 아님.

재실행 시 같은 v0.2 출력 파일을 다시 생성한다. 원본·v0.1 주석은 덮어쓰지 않는다.
원본 SHA-256이 기존 inventory와 다르면 중단한다.
우선 검토 큐에 없더라도 사람 검토가 끝난 것은 아니다. 모든 행의 review_required는 true다.

## 검증

행 수·중복 ID·원본 해시·학생 인용 위치·null/uncertain·기존 100건 보존을 검사한다.
추가로 AI 오류 출력만 존재할 때 시도 양성을 만들지 않는지,
정답 금지·일반 예문을 완성 답안 양성으로 강제하지 않는지 확인한다.
형식·불변식 검증은 사람의 독립 의미 검토를 대체하지 않는다.
