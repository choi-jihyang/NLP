# ② 인증 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 모든 API가 쓸 에러 형식(`{code, message, trace_id}`)과 JWT 권한 확인을 만들고, 교수자 가입·로그인 API를 연다.

**Architecture:** service는 `app/core/errors.py`의 `AppError`만 던지고, `app/api/errors.py`의 핸들러가 표준 바디로 바꾼다. 토큰은 PyJWT(HS256)로 `app/core/tokens.py`에서 발급·검증하고, `app/api/deps.py`의 `Annotated` 의존성이 요청마다 DB의 사용자·역할을 확인한다. 가입·로그인 로직은 `app/services/auth_service.py`(FastAPI 없이 테스트 가능), 라우터는 얇게.

**Tech Stack:** FastAPI, SQLAlchemy 2.0, Pydantic 2 / pydantic-settings, PyJWT 2.x, pytest, ruff.

**Spec:** [docs/superpowers/specs/2026-11-21-auth-design.md](../specs/2026-11-21-auth-design.md) · 에러 카탈로그·수용 기준 [docs/spec/error-handling.md](../../spec/error-handling.md)

> 선행: PR #7, #8 위의 `feature/auth` 브랜치(이미 있음, 설계 문서 커밋됨). 모든 명령은 `backend/`에서: `cd backend`.

## Global Constraints
- 에러 바디는 항상 `{code, message, trace_id}`. `trace_id` = 응답 헤더 `X-Request-Id`. message는 한국어, 내부 원문·비밀값 노출 금지.
- service는 `fastapi`를 import하지 않는다. `AppError(ErrorCode.X)`만 던진다.
- 모든 PK·응답 id 필드 이름은 `seq`(숫자). 토큰 `sub`만 `str(user.seq)`.
- 토큰 유효 기간: 교수자 `TEACHER_TOKEN_HOURS`(기본 12)시간. 학생은 ③이 클래스 `expires_at`을 넘긴다.
- `JWT_SECRET`은 32자 이상. 비었거나 짧으면 설정 로드에서 실패(앱 시작 안 됨).
- 비밀번호 8–128자, UTF-8로 인코딩할 수 없으면 거부. 로그인 실패는 이유와 상관없이 같은 `INVALID_CREDENTIALS`.
- FastAPI 의존성은 `Annotated[..., Depends(...)]`로 쓴다(ruff B008).
- 설정은 `get_settings()`로만 읽는다. 앱 코드에서 `os.environ` 직접 읽기 금지(테스트 `conftest.py`만 예외).
- 파일 200줄 이하(테스트 제외), 타입 힌트, `ruff check` 통과.
- 커밋: `[auth] 한국어 제목` + 빈 줄 + `*` 불릿 + `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
1. **`.env`에 `JWT_SECRET`이 없는 개발자 PC** — 알 수 없는 traceback이 아니라 "JWT_SECRET은 32자 이상…" 한국어 안내로 멈춰야 한다. → Task 2 `test_missing_secret_rejected`
2. **`alg: none`이나 다른 키로 만든 토큰** — 서명 없는 토큰이 통과하면 누구나 교수자가 된다. 반드시 401. → Task 2 `test_unsigned_token_rejected`, `test_other_key_rejected`
3. **대소문자만 다른 같은 이메일로 두 번 가입** (`Teacher@X.test` / `teacher@x.test`) — 계정이 둘 생기면 안 되고 `EMAIL_TAKEN`. → Task 3 `test_duplicate_email_case_insensitive`
4. **`sub`가 숫자가 아닌 토큰** — 500이 아니라 401. → Task 2 `test_non_numeric_sub_rejected`
5. **처리 안 된 예외의 500 응답** — traceback·원문 없이 고정 메시지와 `X-Request-Id` 헤더가 있어야 서버 로그와 대조할 수 있다. → Task 1 `test_unhandled_error_hides_detail`

```python
"""예외 → {code, message, trace_id}. trace_id는 응답 헤더 X-Request-Id와 같다."""

import logging
import uuid
from collections.abc import Awaitable, Callable

from fastapi import FastAPI, Request, Response
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse

from app.core.errors import AppError, ErrorCode

REQUEST_ID_HEADER = "X-Request-Id"
logger = logging.getLogger("thinkguard")


def _trace_id(request: Request) -> str:
    trace_id = getattr(request.state, "trace_id", None)
    return trace_id if isinstance(trace_id, str) else uuid.uuid4().hex


def _error(request: Request, code: ErrorCode, message: str) -> JSONResponse:
    trace_id = _trace_id(request)
    return JSONResponse(
        status_code=code.status,
        content={"code": code.value, "message": message, "trace_id": trace_id},
        headers={REQUEST_ID_HEADER: trace_id},
    )


async def _app_error(request: Request, exc: Exception) -> JSONResponse:
    assert isinstance(exc, AppError)
    return _error(request, exc.code, exc.message)


async def _validation_error(request: Request, exc: Exception) -> JSONResponse:
    assert isinstance(exc, RequestValidationError)
    fields = sorted({str(err["loc"][-1]) for err in exc.errors() if err.get("loc")})
    if not fields:
        return _error(request, ErrorCode.VALIDATION_FAILED, ErrorCode.VALIDATION_FAILED.default_message)
    message = "입력 값이 올바르지 않습니다: " + ", ".join(fields)
    return _error(request, ErrorCode.VALIDATION_FAILED, message)


async def _unhandled_error(request: Request, exc: Exception) -> JSONResponse:
    trace_id = _trace_id(request)
    logger.error("처리되지 않은 예외 trace_id=%s", trace_id, exc_info=exc)  # 원문은 서버 로그에만
    return _error(request, ErrorCode.INTERNAL_ERROR, ErrorCode.INTERNAL_ERROR.default_message)


def install_error_handling(app: FastAPI) -> None:
    app.add_exception_handler(AppError, _app_error)
    app.add_exception_handler(RequestValidationError, _validation_error)
    app.add_exception_handler(Exception, _unhandled_error)

    @app.middleware("http")
    async def add_request_id(request: Request, call_next: Callable[[Request], Awaitable[Response]]) -> Response:
        trace_id = uuid.uuid4().hex
        request.state.trace_id = trace_id
        response = await call_next(request)
        response.headers[REQUEST_ID_HEADER] = trace_id
        return response
```

"""JWT(HS256) 발급·검증. 클레임: sub(str(user.seq)) · role · iat · exp."""

from dataclasses import dataclass
from datetime import datetime

import jwt

from app.core.clock import now_kst
from app.core.config import get_settings
from app.core.enums import Role
from app.core.errors import AppError, ErrorCode
from app.models.user import User

ALGORITHM = "HS256"
REQUIRED_CLAIMS = ["sub", "role", "iat", "exp"]


@dataclass(frozen=True)
class TokenClaims:
    user_seq: int
    role: Role


def issue_token(user: User, expires_at: datetime) -> str:
    """교수자: now_kst() + teacher_token_hours. 학생: ③이 클래스 expires_at을 넘긴다."""
    if expires_at.tzinfo is None:
        raise ValueError("expires_at에는 시간대가 있어야 합니다. now_kst() 기준으로 만드세요.")
    payload = {
        "sub": str(user.seq),
        "role": str(user.role),
        "iat": int(now_kst().timestamp()),
        "exp": int(expires_at.timestamp()),
    }
    return jwt.encode(payload, get_settings().jwt_secret, algorithm=ALGORITHM)


def decode_token(token: str) -> TokenClaims:
    """서명 · 만료 · 형식 · 클레임 값이 하나라도 틀리면 AppError(UNAUTHORIZED)."""
    try:
        payload = jwt.decode(
            token, get_settings().jwt_secret, algorithms=[ALGORITHM], options={"require": REQUIRED_CLAIMS}
        )
        return TokenClaims(user_seq=int(payload["sub"]), role=Role(payload["role"]))
    except (jwt.PyJWTError, ValueError, TypeError) as exc:
        raise AppError(ErrorCode.UNAUTHORIZED) from exc

"""교수자 가입·로그인. FastAPI에 의존하지 않는다(AppError만 던짐)."""

from dataclasses import dataclass
from datetime import timedelta
from functools import cache

from sqlalchemy import select
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Session

from app.core.clock import now_kst
from app.core.config import get_settings
from app.core.enums import Role
from app.core.errors import AppError, ErrorCode
from app.core.security import hash_password, verify_password
from app.core.tokens import issue_token
from app.models.user import User


@dataclass(frozen=True)
class AuthResult:
    access_token: str
    user: User


def normalize_email(email: str) -> str:
    return email.strip().lower()


@cache
def _dummy_hash() -> str:
    """계정이 없을 때도 같은 비용의 해시 계산을 하기 위한 값(비밀 아님)."""
    return hash_password("thinkguard-dummy-password")


def _login_token(user: User) -> str:
    return issue_token(user, now_kst() + timedelta(hours=get_settings().teacher_token_hours))


def signup(db: Session, name: str, email: str, password: str) -> AuthResult:
    email = normalize_email(email)
    if db.scalar(select(User.seq).where(User.email == email)) is not None:
        raise AppError(ErrorCode.EMAIL_TAKEN)
    user = User(role=Role.TEACHER, email=email, password_hash=hash_password(password), name=name, login_at=now_kst())
    db.add(user)
    try:
        db.commit()
    except IntegrityError as exc:  # 동시에 같은 이메일로 가입
        db.rollback()
        raise AppError(ErrorCode.EMAIL_TAKEN) from exc
    return AuthResult(_login_token(user), user)


def login(db: Session, email: str, password: str) -> AuthResult:
    user = db.scalar(select(User).where(User.email == normalize_email(email)))
    stored = user.password_hash if user is not None else None
    if user is None or stored is None:
        verify_password(password, _dummy_hash())
        raise AppError(ErrorCode.INVALID_CREDENTIALS)
    if not verify_password(password, stored):
        raise AppError(ErrorCode.INVALID_CREDENTIALS)
    user.login_at = now_kst()
    db.commit()
    return AuthResult(_login_token(user), user)

"""가입·로그인 요청/응답. 응답 id 필드는 seq(숫자)."""

import re

from pydantic import BaseModel, ConfigDict, field_validator

from app.core.enums import Role
from app.services.auth_service import normalize_email

_EMAIL = re.compile(r"^[^@\s]+@[^@\s]+\.[^@\s]+$")


class SignupRequest(BaseModel):
    name: str
    email: str
    password: str

    @field_validator("name")
    @classmethod
    def _name(cls, value: str) -> str:
        value = value.strip()
        if not 1 <= len(value) <= 100:
            raise ValueError("이름은 1–100자여야 합니다.")
        return value

    @field_validator("email")
    @classmethod
    def _email(cls, value: str) -> str:
        value = normalize_email(value)
        if len(value) > 255 or not _EMAIL.match(value):
            raise ValueError("이메일 형식이 올바르지 않습니다.")
        return value

    @field_validator("password")
    @classmethod
    def _password(cls, value: str) -> str:
        if not 8 <= len(value) <= 128:
            raise ValueError("비밀번호는 8–128자여야 합니다.")
        try:
            value.encode("utf-8")
        except UnicodeEncodeError as exc:
            raise ValueError("비밀번호에 쓸 수 없는 문자가 있습니다.") from exc
        return value


class LoginRequest(BaseModel):
    email: str
    password: str


class UserOut(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    seq: int
    name: str
    email: str | None
    role: Role


class AuthResponse(BaseModel):
    access_token: str
    user: UserOut

"""요청마다 토큰 → DB 사용자 · 역할 확인. 역할은 토큰이 아니라 DB 기준.

내보낸 학생(REMOVED)과 남의 클래스 접근(I7)은 ③ 클래스 API가 참여 상태로 막는다.
"""

from typing import Annotated

from fastapi import Depends
from fastapi.security import HTTPAuthorizationCredentials, HTTPBearer
from sqlalchemy.orm import Session

from app.core.enums import Role
from app.core.errors import AppError, ErrorCode
from app.core.tokens import decode_token
from app.db.session import get_db
from app.models.user import User

_bearer = HTTPBearer(auto_error=False)

DbSession = Annotated[Session, Depends(get_db)]


def get_current_user(
    credentials: Annotated[HTTPAuthorizationCredentials | None, Depends(_bearer)], db: DbSession
) -> User:
    if credentials is None:
        raise AppError(ErrorCode.UNAUTHORIZED)
    claims = decode_token(credentials.credentials)
    user = db.get(User, claims.user_seq)
    if user is None:
        raise AppError(ErrorCode.UNAUTHORIZED)
    return user


CurrentUser = Annotated[User, Depends(get_current_user)]


def require_teacher(user: CurrentUser) -> User:
    if user.role != Role.TEACHER:
        raise AppError(ErrorCode.FORBIDDEN)
    return user


def require_student(user: CurrentUser) -> User:
    if user.role != Role.STUDENT:
        raise AppError(ErrorCode.FORBIDDEN)
    return user


TeacherUser = Annotated[User, Depends(require_teacher)]
StudentUser = Annotated[User, Depends(require_student)]

from fastapi import APIRouter

from app.api.deps import DbSession
from app.schemas.auth import AuthResponse, LoginRequest, SignupRequest, UserOut
from app.services import auth_service

router = APIRouter(prefix="/auth", tags=["auth"])


def _response(result: auth_service.AuthResult) -> AuthResponse:
    return AuthResponse(access_token=result.access_token, user=UserOut.model_validate(result.user))


@router.post("/signup", status_code=201)
def signup(body: SignupRequest, db: DbSession) -> AuthResponse:
    return _response(auth_service.signup(db, body.name, body.email, body.password))


@router.post("/login")
def login(body: LoginRequest, db: DbSession) -> AuthResponse:
    return _response(auth_service.login(db, body.email, body.password))

```
| POST | `/auth/signup` | 공개 | `{name, email, password}` → **201** `{access_token, user{seq, name, email, role}}` 교수자만 가입. 이름 1–100자, 이메일은 소문자로 저장, 비밀번호 8–128자. 오류: `EMAIL_TAKEN`, `VALIDATION_FAILED` ✅ 구현됨 | `signup` |
| POST | `/auth/login` | 공개 | `{email, password}` → `{access_token, user{seq, name, email, role}}`. 실패는 이유와 상관없이 `INVALID_CREDENTIALS`. 교수자 토큰 12시간 ✅ 구현됨 | `login` |
```
