수업 코드와 학번으로

학생은 무료예요. 교수자가 알려준 수업 코드만 있으면 바로 과제를 풀 수 있어요.

입장

수업 코드 + 학번. 기록 열람·붙여넣기 기록 안내에 동의해요.

풀기

문항 옆 AI에게 물어봐요. 내가 시도한 만큼 힌트가 열려요.

제출

혼자 푼 문항은 쓴 개념을 하나 짚고, 다섯 문항을 다 내면 최종 제출.
