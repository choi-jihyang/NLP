## 한눈에 보기 — 시연 흐름
```
교수자: 가입 → 요금제 결제(목업) → 클래스 개설(수업 코드) → 과제 만들기 4단계 → 배포
학생:   수업 코드 + 수업용 ID로 입장(명단 확인 · 참여 요청) → 동의 → 과제 풀이(AI 도움)
        → 문항 제출(마감 전 다시 제출 가능) → 최종 제출 → AI 없이 이해 확인
교수자: 반 리포트 · 간단 제작 채점 · 학생별 기록 → 결과 공개
학생:   내 리포트(점수 · 정답 · 개념별 상태)
```

## 화면 지도
```
/ 시작 (교수자 · 학생 선택)
├─ /login · /signup                          교수자 로그인 · 계정 만들기
├─ 교수자 /teacher
│   ├─ plans                                  요금제 (v4: 카드만, 결제는 개설 때 · 연장은 마이페이지)
│   ├─ mypage                                 마이페이지 (v4 새 화면)
│   ├─ classes                                내 클래스
│   ├─ classes/new                            클래스 개설
│   └─ classes/:classId                       클래스 상세 (과제 목록 · 결과 공개)
│       ├─ ai-settings                        학습 AI 기본값
│       ├─ students                           학생 관리 (참여 요청 · 명단 · 내보내기)
│       ├─ students/:studentId?assignment=    학생별 기록
│       ├─ assignments/new · :id/edit         과제 만들기 4단계
│       ├─ assignments/:id/grading            간단 제작 채점
│       └─ dashboard?assignment=              반 리포트
└─ 학생 /student
    ├─ join                                   수업 입장 · 참여 요청 대기
    ├─ consent?class=                         기록 안내 동의
    ├─ classes                                내 과제
    ├─ mypage                                 마이페이지 (v4 새 화면)
    └─ assignments/:assignmentId              과제 풀이 + 학습 AI
        ├─ check                              이해 확인 (최종 제출 후, AI 없음)
        └─ report                             내 리포트 (결과 공개 후)
```

### 과제 풀이 상세
- **문항:** 문제·코드, 답 입력(객관식 · 출력 예측 · 코드 편집기), 코드 문항은 **공개 테스트만** 실행해 볼 수 있음.
- **제출:** 정오·점수·숨김 테스트 결과는 **보여주지 않음**(결과 공개 때 한꺼번에). 최종 제출 전까지 **다시 제출** 가능, 마지막 답이 채점됨.
- **제출 전 개념 확인:** 힌트 없이 **처음** 낸 문항이면 내 코드에 쓴 개념을 1개 묻는다. 답변에 **AI 작성 신호**가 높으면 1개 더 묻는다(이때는 돌아가기 불가). 판정은 학생에게 안 보이고 교수자 리포트에 참고로만.
- **학습 AI:** 힌트 단계 막대(열린 단계 / 최대), 빠른 질문 버튼. 완성 답안을 바로 요청하면 **도움 방식 고르기**(첫 힌트만 · 내 코드 피드백 · 원래 질문 그대로). 문항을 제출해도 최종 제출 전까지 열려 있음.
- **AI 잠김:** 교수자가 AI를 끈 간단 제작 문항, 개념 확인 중, 최종 제출 후.
- **최종 제출:** 모든 문항을 내면 버튼이 생기고, 한 번 더 확인 후 답과 AI가 잠기며 이해 확인으로 이동.
- 붙여넣기 기록 안내 문구, **판별 과정 표시(시연용)** 체크박스.
