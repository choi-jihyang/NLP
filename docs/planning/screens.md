# 화면 목록 · 화면별 기능 명세

> 상태: **초안** — Figma 작업의 기준. 디자인 토큰(색·폰트)은 `화면시안_v2.html`을 따른다 → `frontend/src/styles/tokens.css`.
> "v2" 열: 화면시안_v2.html에 이미 있는 화면이면 해당 위치, 없으면 **신규**.
> 결정이 필요한 항목은 맨 아래 [결정 필요](#결정-필요)에 모았다.

## 화면 지도
```
/ 시작
├─ /login · /signup
├─ 교수자 /teacher
│   ├─ plans                                   요금제 선택 · 결제 목업
│   ├─ classes                                 내 클래스
│   ├─ classes/new                             클래스 개설
│   └─ classes/:classId                        클래스 상세
│       ├─ ai-settings                         학습 AI 설정
│       ├─ assignments/new · :id/edit          과제 등록
│       ├─ assignments/:id/grading             서술형 채점
│       └─ dashboard                           반 전체 분석
└─ 학생 /student
    ├─ join                                    초대 코드로 참여
    ├─ classes                                 내 과제
    └─ assignments/:assignmentId               과제 풀이 + 학습 AI
```

## 공통
| 화면 | 경로 | v2 | 기능 |
|---|---|---|---|
| 시작 | `/` | 신규 | 서비스 소개 한 줄, 로그인·회원가입 버튼 |
| 로그인 | `/login` | 신규 | 이메일·비밀번호 → 역할에 따라 교수자 `/teacher/classes` 또는 학생 `/student/classes`로 이동. 실패 시 오류 문구 |
| 회원가입 | `/signup` | 신규 | 이름·이메일·비밀번호, 역할 선택(교수자/학생). 교수자는 가입 뒤 요금제 화면으로 |

## 교수자
| 화면 | 경로 | v2 | 기능 |
|---|---|---|---|
| 요금제 선택 | `/teacher/plans` | 신규 | Starter / Pro / Master 비교 카드. 클래스 단위·학생 수 기준·최대 1년. "결제하기"는 **목업**(실제 결제 없이 성공 처리). 연장 버튼(목업) |
| 내 클래스 | `/teacher/classes` | 신규 | 클래스 카드: 과목명, 학생 수 / 상한, 만료일, 과목 유형. "클래스 개설" 버튼 |
| 클래스 개설 | `/teacher/classes/new` | 신규 | 과목명, 학생 수 상한, 요금제 선택 → 개설하면 **초대 코드 발급**·표시(복사 버튼) |
| 클래스 상세 | `/teacher/classes/:classId` | v2 STEP 4 배포 박스 일부 | 초대 코드, 참여 학생 목록, 과제 목록(제출 수), AI 설정·대시보드·과제 등록 바로가기 |
| 학습 AI 설정 | `.../ai-settings` | v2 STEP 3 | 과목 유형(수학/프로그래밍/글쓰기/개념 학습) · 힌트 제공 여부 · 최대 힌트 단계 · 유형별 기본 정책 안내(수학: 한 단계씩 + 다음 단계 예측 유도 / 프로그래밍: 전체 코드 금지, 흐름 설명 + 빈칸 채우기) · 학생별 AI 사용량 상한. **프롬프트 직접 입력 없음**. "학생은 이렇게 경험해요" 요약(v2 STEP 4) |
| 과제 등록 | `.../assignments/new` | v2 STEP 1–2 | 과제 이름·마감일, 문항 추가(객관식·단답형·서술형), 정답·함께 인정할 표기, 문항별 배점, 채점 방식(자동/교수자). 서술형은 채점 기준·모범 답안(선택) |
| 서술형 채점 | `.../assignments/:id/grading` | v2 리포트 "서술형 채점" | 학생별 답안, 채점 기준 참고, 점수·코멘트 입력 → 확정/다시 채점. 붙여넣기 기록이 있으면 **참고 신호** 칩만 표시 |
| 반 전체 분석 | `.../dashboard` | v2 리포트 | 제출 현황, **문항별 오답률**, **힌트를 많이 쓴 문항**, **반 전체가 막히는 지점**(오답 분포), 외부 AI 의심 신호 표(참고용, 점수 영향 없음 문구 고정) |

## 학생
| 화면 | 경로 | v2 | 기능 |
|---|---|---|---|
| 클래스 참여 | `/student/join` | 신규 | 초대 코드 입력 → 참여. 오류: 없는 코드 / 학생 수 상한 도달 / 만료된 클래스 / 이미 참여 |
| 내 과제 | `/student/classes` | 신규 | 참여한 클래스별 과제 목록, 마감일, 제출 상태(미제출·제출·채점 완료) |
| 과제 풀이 | `/student/assignments/:id` | v2 학생 화면 | **왼쪽 문항 / 오른쪽 학습 AI 채팅** 2단. 문항 이동, 답 입력, 제출. 채팅 상단에 힌트 단계(n / 최대). 서술형은 AI 도움 잠김. 혼자 푼 문항은 제출 전 **개념 확인 질문**. 답안 칸 붙여넣기 기록 안내 문구. 사용량 상한 도달 시 안내 메시지 + 입력 잠금 |

## Figma 작업 팁
- Figma 플러그인 **html.to.design**으로 `화면시안_v2.html`을 가져오면 기존 화면을 편집 가능한 레이어로 시작할 수 있다.
- "신규" 화면은 v2의 공통 요소(`.panel`, `.btn`, `.chip`, 그래프 용지 헤더)를 재사용해서 그린다.
