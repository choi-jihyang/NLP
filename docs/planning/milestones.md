## M2 · 11/24 — 로그인 · 클래스 · 학생 입장
시연 시나리오: **교수자 로그인 → 클래스 개설(시작 날짜 선택) → 학생이 수업 코드 + 학번으로 입장 → 교수자가 참여 요청 수락**
- DB 모델(`KstDateTime`, `now_kst()`)과 시드 데이터: 교수자 1, 클래스 1, 학생 3, 프로그래밍 과제 1
- 교수자 가입·로그인(JWT, PBKDF2-SHA512), 학생 입장(수업 코드 + 학번, 가입 없음)
- 클래스 개설·초대 코드·요금제별 학생 수 상한·시작 전 입장 막기, 명단(`is_use`)·참여 요청 수락
- 응답 정책 대문자 + `OFFER_CHOICES`, AI 설정 → 시스템 프롬프트 조립(`build_from_config`) + 테스트
- 프론트: 위 API가 생긴 화면부터 `api/mock/` 대신 실제 호출로 교체

## 위험 요소
- 로컬 LLM 속도·한국어 품질 → M2까지는 Mock으로 진행하고, Ollama + Qwen은 M3 초반에 시연 PC에서 미리 시험한다.
- Qwen 3 계열은 답 전에 생각 과정(thinking)을 출력해 정답이 섞일 수 있다 → 호출할 때 끈다.
- PDF 텍스트 추출에서 코드 들여쓰기가 깨질 수 있다 → 샘플 PDF로 먼저 시험하고, 안 되면 md 양식으로 바꾼다.
- 시연 PC에 Docker가 없으면 코드 실행이 안 된다 → `CODE_RUNNER=mock`으로 대체할 수 있게 유지한다.
- NLP 모델이 늦어질 경우 → 키워드 스텁으로 시연할 수 있게 유지한다.
