## M2 · 11/24 — 핵심 흐름 한 줄
시연 시나리오: **교수자 가입 → 클래스 개설 → AI 설정 → 과제 등록 → 학생이 초대 코드로 참여 → 과제 풀이 중 AI 채팅(정답 요청 시 힌트만) → 제출**
- 회원가입·로그인(JWT, 역할 2개)
- 클래스 개설·초대 코드·학생 수 상한, 학생 참여
- AI 설정 양식 → 시스템 프롬프트 변환 (+ 테스트)
- 과제 등록(객관식·단답형·서술형), 객관식·단답형 자동 채점
- 풀이 화면 + 채팅 (Mock Provider + 키워드 스텁 분류기)
- 시드 데이터: 교수자 1, 클래스 1, 학생 3, 수학·프로그래밍 과제 각 1
