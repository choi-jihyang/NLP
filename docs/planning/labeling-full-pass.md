# 전체 데이터 초벌 주석 결과

상태: **전체 행 처리 완료, 의미 재라벨링은 미완료**

후속 원문 검토와 최신 스냅샷은 [의미 재라벨링 진행 기록](semantic-labeling-progress.md)을 참고한다.
아래 집계는 v0.2 초벌 처리 당시 기록으로 보존한다.

날짜: 2026-11-16. [약한 주석 규칙 v0.2](../spec/student-input-weak-labeling.md).

| 데이터 | 전체 | 기존 AI 의미 검토 | 규칙 기반 약한 주석 | 핵심 라벨 하나 이상 보류 |
|---|---:|---:|---:|---:|
| StudyChat | 16,851 | 50 | 16,801 | 16,624 |
| RECIPE4U | 1,913 | 50 | 1,863 | 1,821 |
| 합계 | 18,764 | 100 | 18,664 | 18,445 |

보류 없는 319건도 의미 검증·사람 승인이 끝난 라벨이 아니다.
사람 검토 0건이며 모든 행의 review_required는 true, gold_eligible은 false다.
기존 100건의 의미 검토 결과와 버전은 그대로 보존했다.
확정 라벨의 학습셋 생성 또는 전체 의미 재라벨링을 완료한 것으로 보고하지 않는다.

## 출력

`data/raw/relabel_v0_2/annotations.jsonl`: 전체 원문·주석·근거·출처·버전.
`data/raw/relabel_v0_2/review_queue.jsonl`: 보류/입력 미검증 우선 검토 큐.
`data/raw/relabel_v0_2/summary.json`: 자료별 집계.
모두 Git 제외다. 재생성은 `python nlp/relabel_all.py`.
원본 이력은 원본 ID로 복원하며 결과 파일에는 이력 전체를 중복 저장하지 않는다.

## 검사

- 원본 SHA-256이 최초 inventory와 일치하는지 검사.
- 총 18,764건 커버리지·원본 ID 중복·학생 근거 인용 위치 검사.
- AI 오류 예시만 있을 때 학생 시도 양성을 만들지 않는 회귀 검사 등 6건 통과.
- 변경한 Python 파일 ruff 검사 통과.
- 이후 AI 응답·essay·미래 학생 턴은 분류 입력에서 제외.
- StudyChat 원본 오류 주석 5건은 핵심 세 라벨을 보류로 격리.

## 결과 해석

기존 AI 초안 100건을 규칙과 비교하면, 양쪽이 모두 판단한 건의 일치 수는
학습 맥락 60/60, 완성 답안 요청 19/21, 시도 근거 73/78이다.
규칙의 보류는 각 38, 78, 19건이며, 이 비교는 동일 AI의 편향된 첫 턴 표본이라
독립 정확도·Macro-F1·사람 간 일치도로 해석할 수 없다.

완성 답안의 범위와 이전 시도 누적은 패턴으로 해결하기 어렵다.
자연어 시도 설명을 규칙이 놓칠 수도 있으므로 음성도 검토 대상이다.
다음 작업은 보류 큐를 대화 단위로 의미 검토하여 규칙 주석을 대체하는 것이다.
원본 기존 라벨을 자동으로 우리 정답에 대응시키거나 null을 false로 채우지 않는다.
