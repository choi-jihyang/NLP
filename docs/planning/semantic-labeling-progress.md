# 원문 의미 재라벨링 진행 기록

상태: **누적 AI 의미 검토 200건, 전체 의미 검토 미완료**
날짜: 2026-11-16. [보충 규칙 v0.3](../spec/student-input-semantic-v0.3.md).

## 이번 작업

보류된 규칙 주석 중 100건의 현재 학생 원문과 허용 이전 대화를 직접 읽고 판단했다.
StudyChat 50건, RECIPE4U 50건이며, 기존 의미 검토 100건과 원본 ID가 겹치지 않는다.
새 주석을 기존 약한 주석 위에 대체 적용하고 이전 스냅샷은 보존했다.
학습 결과나 자동 규칙의 판단을 그대로 전사하지 않았다.

| 배치 | 신규 의미 검토 | 세 라벨 모두 판단 | 하나 이상 보류 유지 |
|---|---:|---:|---:|
| 002: 다중 턴 | 60 | 51 | 9 |
| 003: 코드·문장·적용 사례 | 40 | 30 | 10 |
| 합계 | 100 | 81 | 19 |

여기서 판단 완료는 AI 초안 안에서 null이 없다는 뜻이며 사람의 최종 승인과 다르다.

## 표본 추출

- 배치 002: v0.2 보류 큐의 약한 주석만 대상, 이전 학생 턴 있음, 허용 입력 합계 1,800자 이하.
  이력 6턴 이하, 자료별 30개 대화에서 1건씩. 시드 20261117.
- 배치 003: v0.3의 당시 남은 약한 주석 보류 큐, 입력 합계 2,200자 이하·이력 6턴 이하.
  코드·문장 태그·시도/생각 표현으로 후보를 모아 자료별 20개 대화에서 1건씩. 시드 20261118.
- 길이·표현 기준으로 선정했으므로 자료 전체를 대표하지 않는다.
- 배치 사이에는 같은 대화의 서로 다른 턴이 포함될 수 있다. 평가 분할은 아직 하지 않았다.
- 실제 선정 입력·원본 ID는 각 배치의 input.json에 보존했다.

## 주요 판단

- 앞 AI의 코드만 존재하고 학생은 설명만 질문하면 자기 시도 근거 없음으로 판단.
- 학생의 구체 수정안·실행 실패·적용 예시·논거는 오류가 있어도 시도 근거로 인정.
- 자기 에세이 검토를 요청한 뒤 보낸 문장은 관찰 가능한 수행 흔적으로 인정.
- 특정 과제의 표·객관식 답과 글 분량 확장·주제문 대행은 완성 산출물 요청으로 판단.
- 기성 자료를 표나 마크다운으로만 정리하는 요청은 새 풀이 대행과 구분.
- 외부 이미지 내용, 코드 출처, 번역의 평가 범위가 불명확한 경우는 보류 유지.
- 이전 AI의 잘못된 설명·불명확한 통계는 학생 시도 근거로 쓰지 않음.
- 현재 시도가 없어도 과거 같은 글의 구체 학생 문장이 있으면 누적 양성 근거로 기록.

## 최신 파일과 전체 상태

전체 최신 스냅샷은 Git 제외인 `data/raw/relabel_v0_3/annotations.jsonl`이다.

- 전체 18,764건 유지.
- AI 의미 검토 누적 200건. 여전히 사람 검토 0건.
- 약한 주석만 있는 행 18,564건.
- 우선 검토 큐 18,364건. 이전 18,445건에서 81건 감소.
- 문맥은 이해했지만 판단 기준·출처가 부족한 신규 19건도 검토 큐에 남김.
- 보류 없는 규칙 주석도 의미 검토 완료로 표시하지 않음.

로컬 검토본:

- `data/raw/semantic_batch_002/review.md`
- `data/raw/semantic_batch_003/review.md`

각 배치에는 input.json, decisions.json, past_evidence.json, annotations.jsonl, summary.json도 보존한다.
재생성은 `python nlp/build_semantic_batch.py data/raw/semantic_batch_002` 등의 명령을 사용한다.
`python nlp/apply_semantic_reviews.py`로 전체 스냅샷을 재생성한다.
배치 간 같은 원본 ID가 중복되면 자동 덮어쓰지 않고 충돌을 알린다.

## 검증

신규 100건의 학생 원문·전체 허용 이력을 원본에서 재구성해 일치 확인했다.
현재 및 과거 학생 발화 인용 위치를 검사하고 AI 발화는 근거로 사용하지 않았음을 확인했다.
18,764건의 전체 커버리지·원본 ID 유일성·신규 주석 반영·null/uncertain 일관성을 확인했다.
변경한 주석 조립·적용 스크립트의 ruff 검사가 통과했다.
형식·출처 검증이며 독립된 사람 간 일치도·모델 성능 검증은 아니다.
